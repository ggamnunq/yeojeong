- `PRIVACY` 동의서를 고치지 않은 이유:
  1. **파일 가져오기 중복 확인** — 0.2 판단(README 3-3절·R-42)과 같이 파일 가져오기는 동의 항목이 아니라 계약 이행 처리다. 이번에 바뀌는 것은 "대조값을 보내는 범위"(고른 결제 → 목록의 결제 전부, 저장 안 함)이고, 동의서 결제 행의 항목·목적·보유 기간은 그대로다.
  2. **화면 오류 기록** — 동의서 7행 "서비스 안전성 확보, 장애 대응 \| 접속 IP 주소, 접속 일시, 브라우저·운영체제 정보 \| 3개월"과 목적·보유 기간이 같고, 처리 근거가 정당한 이익(동의 아님)이라 처리방침에 밝히는 것으로 충분하다고 본다. 동의서에 넣으면 `PRIVACY` 0.3(해시 변경)이 생기지만 재동의는 여전히 필요 없어 회원 쪽 차이가 없다. → README 6절 R-44.

- 처리방침 0.3 동기화(`sync-legal.mjs`): `v0.3/`에는 처리방침만 있으므로 나머지 문서는 `v0.2/`(오픈소스 고지는 `v0.1/`)에서 가져온다. `/privacy`는 시행일(`2026-11-07`) 전까지 0.2가 현행, `/privacy?v=0.3` = 예정본. 시행일부터 `/privacy` = 0.3, `?v=0.2`·`?v=0.1` = 이전 버전.

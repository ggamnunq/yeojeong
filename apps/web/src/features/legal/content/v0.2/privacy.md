## 제1조(개인정보의 처리 목적)

운영자는 다음의 목적을 위하여 개인정보를 처리합니다. 처리한 개인정보는 다음 목적 외의 용도로 이용하지 않으며, 이용 목적이 바뀌는 경우에는 「개인정보 보호법」 제18조에 따라 별도의 동의를 받는 등 필요한 조치를 합니다.

1. **회원 가입과 관리**: 카카오 로그인을 통한 회원 식별과 인증, 가입 의사 확인, 만 14세 미만 아동의 가입 제한, 회원 자격 유지와 관리, 부정 이용 방지, 서비스 관련 고지와 통지
2. **그룹 여행 서비스 제공**: 그룹(여정)의 생성·참여·관리, 같은 그룹 멤버에게 닉네임과 프로필 사진 표시, 지출 현황과 예산 표시, 환율 적용
3. **결제 기록과 정산**: 회원이 직접 입력하거나 결제 앱 거래 내역 파일에서 골라 가져온 결제 기록의 저장과 지갑 표시, 파일에서 가져온 같은 결제의 중복 추가 방지, 여정 연결, 개인·공동 분류, 공동 결제의 같은 그룹 멤버 공유, 정산 정보의 계산과 표시
4. **서비스 안전성 확보**: 접속 기록과 결제 기록 접근 기록의 관리, 비정상 이용과 보안 위협의 탐지·차단, 장애 대응, 분쟁 대응을 위한 기록 보존
5. **문의와 권리 행사 처리**: 문의 접수와 답변, 열람·정정·삭제·처리정지·동의 철회·탈퇴 요청의 처리
6. **카드 내역 불러오기(시범 운영)**: 이용 권한을 받고 별도로 동의한 회원이 입력한 카드사 로그인 정보로 본인 카드의 승인내역을 한 번 조회하여 보여 주기, 회원이 고른 결제의 지갑 기록, 같은 결제의 중복 추가 방지, 카드사 계정 잠김 예방, 시범 운영 대상 회원의 이용 권한 관리

운영자는 「개인정보 보호법」 제15조제3항과 제17조제4항에 따른 추가적인 이용·제공을 하지 않습니다.

운영자가 회원에게 별도의 동의를 받아 제공하는 기능의 개인정보 처리는 이 처리방침과 함께 그 기능의 동의서에서 정한 바에 따릅니다. 카드 내역 불러오기(제6호)는 「카드 내역 조회 동의서」(https://jinyeojeong.com/consents/CARD_IMPORT)에 동의한 회원에게만 적용되며, 동의하지 않은 회원의 개인정보는 이 기능을 위하여 처리하지 않습니다.

**3. 결제 기록(회원이 직접 입력하거나 결제 앱 거래 내역 파일에서 골라 가져옴)**

- 작성자가 다른 멤버를 결제자로 지정하여 대신 기록하는 경우, 결제자로 지정된 멤버의 결제 정보(누가 얼마를 냈는지)는 작성자가 입력합니다. 이 결제는 항상 공동 결제로 같은 그룹 멤버에게만 표시되며, 결제자로 지정된 멤버는 제8조에 따라 정정이나 삭제를 요구할 수 있습니다.
- 결제 앱 거래 내역 파일 가져오기에서는 파일 원본과 회원이 고르지 않은 거래를 저장하지 않습니다. 또한 송금·홍바오 등 개인 간 거래(상대방의 이름이 들어 있음), 충전·출금 등 결제가 아닌 거래, 결제수단 정보(카드 끝 4자리 등), 가맹점 주문번호, 메모는 목록에 보여 주지 않고 가져오지 않습니다. 가져온 결제는 회원이 직접 입력한 결제와 같이 지갑에 기록되고, 결제 일시가 회원이 참여한 여정의 기간에 들면 그 여정에 미확정 결제로 연결되며, 분류·공개·수정·삭제도 같습니다. 운영자는 이 기능을 위하여 파일 처리를 외부 업체에 맡기지 않습니다.
- 운영자는 6번 표의 카드 내역 불러오기로 회원이 고른 결제 외에는 결제 기록을 금융회사나 카드사로부터 받지 않으며, 결제수단(카드·계좌)의 정보를 저장하지 않습니다.

| 필수(저장하지 않음, 현대카드·하나카드만) | 카드번호(전체, 암호화된 연결로 운영자의 서버를 거쳐 전달), 카드 비밀번호(현대카드 4자리, 하나카드 앞 2자리. 회원의 브라우저에서 암호화) | 회원이 직접 입력 | 동의 |
| 필수(저장하지 않음, 카드사가 요구할 때 — 현대카드·하나카드는 없음) | 추가 인증 정보: 문자 인증번호, 추가 인증 진행 정보 | 회원이 직접 입력, 서비스가 생성하여 회원의 브라우저에 암호화 보관 | 동의 |
| 필수(저장하지 않음) | 조회 기간(최대 92일, 오늘부터 1년 이내. 카드사에 따라 더 짧을 수 있음)의 카드 승인내역: 승인 일시, 가맹점명, 승인 금액과 통화, 원화 청구 금액, 해외 승인 여부, 승인·취소 구분 | 수탁자(헥토데이터)가 회원을 대신하여 카드사에서 조회 | 동의 |
| 필수 | 회원이 고른 결제: 결제 일시(날짜·시각), 금액, 통화, 가맹점명, 카드사 원화 청구 금액(있는 경우) | 회원이 불러온 승인내역에서 골라 추가 | 동의 |
| 생성 | 중복 확인값(카드사·승인번호·승인 일시·승인 금액·통화를 운영자의 비밀키로 되살릴 수 없게 변환한 값), 조회 이력(회원, 조회 일시, 카드사 코드, 건수, 결과 코드. 불러온 내역의 내용은 남기지 않음), 로그인 실패 기록과 조회 횟수 제한 기록(회원, 카드사 코드, 실패 횟수와 마지막 실패 시각), 예비 조회 방식에서만 조회용 연결 식별값 | 서비스 이용 과정에서 생성 | 동의, 서비스 보안을 위한 정당한 이익(제15조제1항제6호) |
| 생성 | 카드 내역 불러오기 이용 권한(권한 여부, 부여·회수 일시) | 운영자가 관리자 페이지에서 부여·회수 | 계약 이행(제15조제1항제4호) |

- 카드사 로그인 정보, 카드번호와 카드 비밀번호, 추가 인증 정보, 불러온 승인내역 원본은 운영자의 서버에 저장하지 않으며, 회원이 고른 결제만 저장합니다. 승인번호 원문, 카드 끝 4자리와 카드 이름도 저장하지 않습니다.
- 카드사 조회는 운영자가 위탁한 주식회사 헥토데이터(CODEF)가 처리합니다(제5조). 운영자는 조회를 위한 헥토데이터의 연결 정보를 만들지 않으며, 예비 조회 방식에서 만들면 조회 직후 삭제합니다.
- 카드 승인내역은 개인신용정보에 해당할 수 있으므로, 운영자는 이를 「신용정보의 이용 및 보호에 관한 법률」에 따른 개인신용정보로 보고 처리합니다.

② 운영자는 「개인정보 보호법」 제23조의 민감정보와 제24조의 고유식별정보(주민등록번호 등)를 처리하지 않습니다.

③ 운영자는 회원의 이메일 주소와 전화번호를 수집하지 않습니다. 다만, 회원이 운영자에게 이메일로 문의하는 경우 그 이메일 주소는 제1항 4번 표와 같이 문의 처리에만 씁니다. 운영자는 계좌번호, 공동인증서 등 인증수단, 계좌의 거래내역, 계좌 잔액·카드 한도, 카드 유효기간과 CVC를 수집하지 않습니다. 카드 내역 불러오기에서 회원이 입력하는 카드사 로그인 아이디와 비밀번호, 현대카드·하나카드의 카드번호와 카드 비밀번호, 추가 인증 정보와 불러온 카드 승인내역은 제1항 6번 표와 같이 조회에만 쓰고 저장하지 않습니다. 비밀번호와 카드 비밀번호는 회원의 브라우저에서 암호화되어 전달되므로 운영자는 원문을 볼 수 없습니다. 카드번호는 암호화된 연결(HTTPS)로 운영자의 서버를 거쳐 수탁자에게 전달되며, 운영자는 이를 저장하거나 기록하지 않습니다. 결제 앱 거래 내역 파일 가져오기에서 회원이 올린 파일은 회원의 기기 안에서만 읽으므로 운영자는 그 파일을 받지 않으며, 제1항 3번 표 아래와 같이 회원이 고른 결제 외의 거래와 정보는 수집하지 않습니다.

## 제3조(개인정보의 처리와 보유 기간)

① 운영자는 법령에 따른 보유·이용 기간 또는 정보주체에게 동의받은 보유·이용 기간 안에서 개인정보를 처리하고 보유합니다.

② 항목별 보유 기간은 다음과 같습니다.

| 항목 | 보유 기간 | 근거 |
|---|---|---|
| 회원 정보(카카오 회원번호, 닉네임, 프로필 사진 주소) | **탈퇴할 때까지(탈퇴 처리 시 즉시 삭제).** 마지막 로그인일부터 3년 동안 이용하지 않으면 탈퇴로 보아 즉시 삭제(제7조제6항) | 동의 |
| 가입 대기 정보(가입을 마치기 전의 카카오 회원번호·닉네임·프로필 사진 주소) | 가입 완료 또는 30분 경과 시 파기 | 동의 |
| 로그인 세션 정보 | 로그아웃하거나 세션이 만료될 때까지(최대 30일, 이용하면 연장) | 계약 이행 |
| 그룹·여정 정보, 공동 결제, 부담 기록, 변경 이력, 정산 정보 | **여정 종료일부터 3년.** 그룹이 삭제되거나 모든 멤버가 나간 그룹은 그때부터 30일 이내 파기 | 계약 이행 |
| 여정의 미확정 결제·개인 결제 | 여정 종료일부터 3년. 다만 작성자가 삭제하거나 탈퇴하면 즉시 파기 | 계약 이행 |
| 지갑 기록 | 회원이 삭제하거나 탈퇴할 때까지(제7조제6항의 장기 미이용 포함). 연결한 여정이 파기되어도 지갑 기록은 남음 | 계약 이행 |
| 결제 앱 거래 내역 파일에서 가져온 결제와 거래 번호 대조값 | 직접 입력한 결제와 같음: 여정에 연결된 결제는 여정 종료일부터 3년, 지갑에만 있는 결제는 회원이 삭제하거나 탈퇴할 때까지(제7조제6항의 장기 미이용 포함). 연결한 여정이 파기되어도 지갑 기록은 남음 | 계약 이행 |
| 결제 앱 거래 내역 파일 원본, 회원이 고르지 않은 거래 | **저장하지 않음.** 파일은 회원의 기기 안에서만 읽고 운영자의 서버로 보내지 않음 | — |
| 카드 내역 불러오기로 추가한 결제와 중복 확인값 | 직접 입력한 결제와 같음: 여정에 연결된 결제는 여정 종료일부터 3년, 지갑에만 있는 결제는 회원이 삭제하거나 탈퇴할 때까지(제7조제6항의 장기 미이용 포함). 카드 내역 조회 동의를 철회하여도 남음(제8조제2항) | 동의 |
| 카드 내역 불러오기의 카드사 로그인 정보, 카드번호와 카드 비밀번호, 추가 인증 정보, 불러온 승인내역 원본 | **저장하지 않음.** 조회를 마치면 즉시 파기(추가 인증 진행 정보는 회원의 브라우저에서 160초(약 2분 40초)가 지나면 파기) | 동의 |
| 카드 내역 조회용 연결 식별값(예비 조회 방식에서만) | 조회 직후 삭제(수탁자에 등록한 연결도 함께 삭제). 일시적 오류로 삭제가 늦어지면 회원 식별 정보 없이 연결 식별값만 암호화하여 삭제될 때까지 보관 | 동의 |
| 카드 내역 조회 이력(내역의 내용 없음) | 1년 | 동의, 서비스 보안 |
| 카드 내역 불러오기의 로그인 실패 기록과 조회 횟수 제한 기록 | **7일** 보관 후 파기 | 동의, 서비스 보안 |
| 카드 내역 불러오기 이용 권한 | 권한이 회수되거나 탈퇴할 때까지 | 계약 이행 |
| 탈퇴한 회원의 공동 결제·부담·정산 기록(회원 식별 정보 없이 "탈퇴한 멤버"로 표시, 남는 항목은 제7조제5항) | 그 그룹 기록의 보유 기간(여정 종료일부터 3년) | 같은 그룹 다른 멤버의 정산 정보 유지(제15조제1항제6호) |
| 약관·동의 이력 | 동의 철회 또는 탈퇴 후 3년. 탈퇴 후에는 회원 정보 대신 대조값(제7조제5항)으로만 보관 | 동의 사실의 입증 |
| 결제 기록 접근 기록 | 1년 | 「개인정보의 안전성 확보조치 기준」 |
| 운영자의 개인정보 처리 기록(관리자 페이지 접속기록, 데이터베이스 직접 접속 기록, 클라우드 감사 로그) | 1년 이상(클라우드 감사 로그는 400일) | 「개인정보의 안전성 확보조치 기준」 |
| 서비스 접속 기록(접속 IP 주소, 접속 일시 등) | **3개월**(대한민국(서울)에 93일 동안 보관한 뒤 자동 삭제) | 「통신비밀보호법」 제15조의2, 같은 법 시행령 제41조 |
| 문의 기록(이메일 주소, 문의 내용) | 처리 완료일부터 1년 | 계약 이행 |
| 권리 행사(열람·정정·삭제·처리정지·동의 철회·탈퇴) 처리 기록 | 처리 완료일부터 3년(처리되지 않은 요청은 요청일부터 3년). 회원 정보 대신 대조값으로만 보관 | 법령상 의무 이행의 입증 |

③ 운영자는 현재 데이터베이스 사업자의 자동 백업을 사용하지 않습니다. 앞으로 데이터베이스 백업을 두는 경우 그 보존 기간은 30일 이내로 하며, 백업에 남은 정보는 보존 기간이 지나면 자동으로 삭제되고 그때까지 복구 외의 목적으로 사용하지 않습니다.

④ 운영자는 현재 유료 서비스를 제공하지 않으므로 「전자상거래 등에서의 소비자보호에 관한 법률」에 따른 거래 기록을 보존하지 않습니다. 유료 서비스를 도입하는 경우 이 처리방침을 변경하여 알립니다.

## 제4조(개인정보의 제3자 제공과 서비스 안에서의 공개)

① 운영자는 정보주체의 개인정보를 제1조의 목적 범위에서만 처리하며, 정보주체의 개인정보를 제3자에게 제공하지 않습니다. 다만, 「개인정보 보호법」 제17조와 제18조에 해당하는 경우(정보주체의 별도 동의, 법률의 특별한 규정 등)에는 그러하지 않습니다.

② 다음 정보는 그룹 기능을 제공하기 위하여 같은 그룹에 참여 중인 멤버에게 서비스 화면으로 표시됩니다. 이는 회원이 이용하는 서비스의 내용 그 자체로서 서비스 이용계약의 이행(「개인정보 보호법」 제15조제1항제4호)에 따른 것이며, 그 밖의 사람에게는 표시하거나 제공하지 않습니다.

| 표시되는 정보 | 표시되는 상대 | 표시되는 시점과 범위 |
|---|---|---|
| 닉네임, 프로필 사진, 그룹장 여부, 참여 순서, 나간 멤버 또는 탈퇴한 멤버인지 여부 | 같은 그룹 멤버 | 그룹에 참여한 때부터 |
| **공동 결제**: 결제의 내용, 결제 일시, 결제 금액(원래 통화 금액과 원화 환산액), 결제자 닉네임, 부담 인원과 1인 부담액, 변경 여부 | 같은 그룹에 참여 중인 멤버 | 회원이 결제를 공동 결제로 입력하거나 공동으로 정한 때부터. 작성자가 여정 진행 중에 개인 결제로 바꾸거나 삭제하면 그때부터, 열람하는 멤버가 그룹에서 나가면 그때부터 볼 수 없음 |
| 부담 인원으로 지정된 사실과 그 부담액, 정산 정보 가운데 본인의 결제 합계·부담액·받을 돈 또는 보낼 돈 | 같은 그룹 멤버 | 공동 결제에 포함된 때부터, 정산 정보는 여정 종료 후 |
| 개인 결제의 **건수**(내용·금액 없음) | 같은 그룹 멤버 | 여정 종료 후 정산 화면 |
| 그룹 전체의 미확정 결제 **건수**(누구의 결제인지와 금액 없음) | 그룹장 | 그룹장이 여정을 직접 종료할 때 |

- 지갑 기록, 미확정 결제, 개인 결제의 내용은 작성자 본인에게만 표시됩니다.

## 제7조(개인정보의 파기 절차와 방법)

① 운영자는 보유 기간이 지나거나 처리 목적을 달성하는 등 개인정보가 필요 없게 된 경우, 정보주체가 동의를 철회하거나 탈퇴한 경우에는 지체 없이(5일 이내) 그 개인정보를 파기합니다.

② 다른 법령에 따라 개인정보를 계속 보존하여야 하는 경우에는 해당 개인정보를 다른 개인정보와 분리하여 저장·관리하며, 보존하는 항목과 근거는 제3조제2항의 표와 같습니다.

③ 파기 절차는 다음과 같습니다.
1. 보유 기간 경과 등 정해진 사유에 따른 파기는 개인정보 보호책임자가 정한 파기 기준에 따라 매일 자동으로 처리합니다.
2. 탈퇴 등 개별 요청에 따른 파기는 본인 확인 후 처리하고, 파기 일시와 대상을 기록합니다.

④ 파기 방법은 다음과 같습니다.
1. 전자적 파일 형태의 정보는 복구하거나 다시 살릴 수 없는 방법으로 영구 삭제합니다. 삭제 표시만 해 둔 정보(삭제된 그룹 등)는 매일 실행하는 파기 작업으로 삭제 표시 후 30일 이내에 영구 삭제합니다. 회원이 삭제한 결제와 지갑 기록은 삭제할 때 바로 영구 삭제합니다.
2. 문의 이메일은 보유 기간이 지나면 메일함에서 영구 삭제합니다.
3. 카드 내역 불러오기에서 입력한 카드사 로그인 정보, 카드번호와 카드 비밀번호, 추가 인증 정보, 불러온 승인내역 원본은 운영자의 서버에 저장하지 않으며, 조회를 마치면 처리 중이던 정보를 즉시 지웁니다. 로그인 실패 기록과 조회 횟수 제한 기록은 7일이 지나면 지웁니다. 예비 조회 방식에서 만든 조회용 연결 정보는 조회 직후 삭제하며, 일시적 오류로 삭제가 늦어지면 회원을 알아볼 수 있는 정보 없이 연결 식별값만 암호화하여 보관하고 삭제 외의 목적으로 쓰지 않으며 삭제될 때까지 다시 시도합니다.
4. 종이에 출력한 정보는 분쇄하거나 소각합니다.

⑤ 회원이 탈퇴하면 운영자는 회원 정보(카카오 회원번호, 닉네임, 프로필 사진 주소)를 **즉시 삭제**하고, 회원의 지갑 기록, 미확정 결제와 개인 결제도 함께 삭제합니다. 다만, 같은 그룹 다른 멤버의 정산 정보가 맞도록 다음 기록은 회원을 식별할 수 있는 정보 없이 남깁니다.

| 동의 기록, 탈퇴 처리 기록 | 동의 항목·버전·일시, 탈퇴 요청·처리 일시 | 회원 정보 대신 회원 식별자를 운영자의 비밀키로 변환한 대조값(HMAC-SHA256)만 저장 | 동의 사실과 탈퇴 처리 사실의 입증 | 제3조제2항의 기간 |

대조값은 동의 기록과 탈퇴 처리 기록을 서로 대조하는 데에만 쓰며, 운영자는 이 값을 다른 정보와 결합하여 탈퇴한 회원을 다시 알아보는 데 쓰지 않습니다. 대조값을 포함한 위 기록도 개인정보로 보아 이 처리방침에 따라 보호하고 보유 기간이 지나면 파기합니다.

⑥ 회원이 마지막으로 로그인한 날부터 3년 동안 서비스를 이용하지 않으면 운영자는 탈퇴로 보아 제5항과 같이 처리합니다. 운영자는 회원의 이메일 주소나 전화번호를 수집하지 않아 해당 회원에게 개별적으로 미리 알릴 수 없으므로, 다음 방법으로 사전 통지를 갈음합니다.
1. 장기 미이용 기준과 처리 방법을 이 처리방침에 상시 게시하고, 서비스 화면(홈과 마이페이지 상단의 공지 배너)으로 안내합니다.
2. 회원이 운영자에게 연락처를 알려 준 경우에는 처리 예정일 30일 전까지 그 연락처로 알립니다.
3. 처리 예정일 전에 회원이 로그인하면 3년의 기간은 그날부터 다시 계산됩니다.

## 제9조(개인정보의 안전성 확보 조치)

운영자는 「개인정보 보호법」 제29조와 「개인정보의 안전성 확보조치 기준」에 따라 다음과 같은 조치를 하고 있습니다.

1. **관리적 조치**
   - 개인정보를 처리하는 사람을 운영자 본인으로 한정합니다.
   - 운영자가 문의 처리, 권리 행사 요청 처리 등으로 회원의 개인정보를 열람하거나 조치할 때에는 **관리자 페이지**만 이용합니다. 관리자 페이지는 아이디·비밀번호와 **2단계 인증**을 거쳐야 접속할 수 있습니다. 관리자 페이지에서 한 모든 열람과 조치는 접속기록(운영자 계정, 일시, 접속한 곳의 주소, 대상 회원·정보, 수행한 업무)으로 남겨 1년 이상 보관합니다.
   - 데이터베이스에 직접 접속하는 것은 장애 대응 등 관리자 페이지로 처리할 수 없는 불가피한 경우로 한정합니다. 이 경우 반드시 사유를 입력하는 접속 절차를 거치며, 접속 시작·종료 시각과 사유를 1년 이상 기록합니다.
   - 클라우드 사업자(Google Cloud)의 감사 로그에도 운영 환경에서 정보를 열람한 기록이 남으며, 400일 동안 보관합니다.
   - 운영 환경의 접근 권한을 용도별로 나누어 최소한으로 부여하고, 권한을 변경하거나 말소한 기록을 보관합니다.
   - 카드 내역 불러오기의 이용 권한은 운영자가 관리자 페이지에서만 부여하거나 회수하며, 그 기록을 관리자 페이지 접속기록으로 남깁니다.
2. **기술적 조치**
   - **전송 구간 보호**: 모든 통신에 TLS 1.2 이상을 적용하고 HTTPS 접속만 허용합니다. 서버와 데이터베이스 사이의 연결도 인증서를 검증하는 암호화 연결만 사용합니다.
   - **접근 통제**: 결제와 정산 정보에 대한 모든 요청에서 요청한 회원이 그 그룹의 멤버인지, 그 결제의 작성자인지를 서버에서 확인합니다. 지갑 기록, 미확정 결제, 개인 결제는 작성자가 아닌 회원에게 보내는 응답에 아예 포함하지 않습니다. 데이터베이스는 운영자의 서버를 통해서만 접근할 수 있고, 운영 서버는 운영자의 웹 전송 경로를 거친 요청만 받습니다.
   - **인증 정보 보호**: 로그인 세션은 추측할 수 없는 무작위 값을 쓰고 서버에는 그 해시값만 저장합니다. 세션 쿠키는 스크립트가 읽을 수 없고 HTTPS로만 전송되도록 설정합니다. 다른 사이트에서 위조한 요청은 요청 출처를 확인하여 거부합니다.
   - **카드 내역 불러오기**: 카드사 비밀번호와 카드 비밀번호는 회원의 브라우저에서 조회 업체(CODEF)의 공개키로 암호화하여 전달하므로 운영자의 서버는 원문을 볼 수 없습니다. 화면은 공개키가 바뀌지 않았는지 지문으로 확인한 뒤에만 암호화하며, 지문이 다르면 암호화하지 않고 조회를 진행하지 않습니다. 카드사 아이디와 카드번호(현대카드·하나카드)는 암호화된 연결(HTTPS)로 운영자의 서버를 거쳐 CODEF로 전달되며, 운영자는 이를 저장하거나 로그에 남기지 않습니다. 카드사 로그인 정보와 불러온 승인내역 원본은 저장하지 않고, 같은 카드사에 로그인이 연속하여 실패하면 카드사 계정 잠김을 막기 위하여 일정 시간 조회를 제한합니다. 같은 결제의 중복 추가를 막는 값은 승인번호 등을 운영자의 비밀키로 되살릴 수 없게 변환(HMAC)하여 저장합니다.
   - **결제 앱 거래 내역 파일 가져오기**: 회원이 올린 파일은 회원의 브라우저 안에서만 읽고 운영자의 서버나 외부 업체로 보내지 않습니다. 서버에는 회원이 고른 결제의 일시·금액·통화·가맹점명과 거래 번호 대조값만 전송하여 저장하며, 거래 번호 원문은 저장하지 않습니다.
   - **접근 기록 관리**: 회원이 결제 기록을 조회, 추가, 수정, 분류, 삭제하거나 탈퇴할 때마다 접근 기록을 남겨 1년 동안 보관합니다. 운영자의 관리자 페이지 접속기록과 데이터베이스 직접 접속 기록은 1년 이상 보관하고 정기적으로 점검합니다.
   - **변환 저장**: 동의 기록과 접근 기록의 접속 IP 주소는 되살릴 수 없는 값으로 변환하여 저장합니다.
   - **기록 최소화**: 결제의 내용과 금액, 세션 값, 카카오 회원번호의 원문은 서비스 로그에 남기지 않습니다. 카드 내역 불러오기의 로그인 정보(암호화된 값 포함), 카드번호와 카드 비밀번호, 추가 인증 정보, 불러온 승인내역도 서비스 로그에 남기지 않습니다.
   - **보안 위협 대응**: 요청 횟수를 제한하고, 보안 헤더를 적용하며, 사용하는 소프트웨어의 취약점을 자동으로 점검합니다. 외부의 보안 취약점 신고를 비공개로 받습니다.
   - **비밀값 관리**: 서버의 비밀값은 클라우드 비밀 관리 서비스에만 보관하며 소스 코드에 넣지 않습니다.
3. **물리적 조치**
   - 운영자는 자체 전산실을 두지 않고 클라우드 사업자의 데이터센터를 이용하며, 데이터센터의 출입 통제 등 물리적 보안은 각 사업자의 보안 인증 기준에 따릅니다.
4. **유출 등에 대한 대응**
   - 개인정보가 유출, 위조, 변조, 훼손, 분실, 도난된 사실을 알게 된 경우 「개인정보 보호법」 제34조에 따라 지체 없이 정보주체에게 알리고 관계 기관에 신고합니다. 정보주체의 연락처가 없는 경우에는 서비스 화면(홈과 마이페이지 상단의 공지 배너)에 게시하여 알립니다.

## 제10조(개인정보 자동 수집 장치의 설치·운영과 거부)

① 운영자는 로그인 상태 유지와 보안을 위하여 꼭 필요한 쿠키와 브라우저 저장소만 사용합니다. 광고나 이용 행태 분석을 위한 쿠키와 제3자 분석 도구는 사용하지 않습니다.

| 이름 | 종류 | 목적 | 보관 기간 |
|---|---|---|---|
| `yj_session` | 쿠키(필수) | 로그인 상태 유지 | 최대 30일(이용하면 연장), 로그아웃 시 삭제 |
| `yj_signup` | 쿠키(필수) | 가입 절차 진행 상태 유지 | 30분 |
| `yj_oauth` | 쿠키(필수) | 카카오 로그인 요청의 위조 방지와 로그인 후 돌아갈 화면 기억 | 10분 |
| `yj:lastTripId`, `yj:payView:{회원 식별값}` | 브라우저 저장소(localStorage) | 마지막으로 본 여정, 결제내역 보기 방식 등 화면 설정 기억 | 회원이 브라우저에서 지울 때까지 |
| `yj:signup:returnTo` 등 | 브라우저 저장소(sessionStorage) | 가입을 마친 뒤 돌아갈 화면 기억 | 브라우저 탭을 닫을 때까지 |

② 회원은 웹 브라우저 설정에서 쿠키 저장을 거부하거나 저장된 쿠키와 브라우저 저장소를 삭제할 수 있습니다. 다만, 필수 쿠키를 거부하면 로그인이 필요한 서비스를 이용할 수 없습니다.

## 제11조(해당하지 않는 처리)

운영자는 다음의 처리를 하지 않습니다. 앞으로 하게 되는 경우에는 이 처리방침을 변경하여 미리 알립니다.

1. **만 14세 미만 아동의 개인정보 처리**: 만 14세 미만 아동은 회원으로 가입할 수 없으며, 회원이 만 14세 미만인 사실을 알게 되면 그 개인정보를 지체 없이 파기합니다.
2. **행태정보 수집과 맞춤형 광고**
3. **가명정보 처리**
4. **완전히 자동화된 결정**: 정산 정보 계산, 중복 의심 표시는 작성자가 입력한 결제와 정한 분류·부담 인원에 따른 계산과 표시이며, 정보주체의 권리나 의무에 중대한 영향을 미치는 「개인정보 보호법」 제37조의2의 자동화된 결정에 해당하지 않습니다. 계산 방식에 대한 설명은 운영자에게 요청할 수 있습니다.
5. **고정형·이동형 영상정보처리기기의 운영**
6. **민감정보와 고유식별정보의 처리**
7. **금융회사·카드사 등으로부터의 개인신용정보 수집**: 다만, 카드 내역 불러오기(제2조제1항 6번 표)에 동의한 회원이 이 기능을 이용하는 경우에는 그 회원 본인 카드의 승인내역을 조회하고 회원이 고른 결제를 저장합니다.

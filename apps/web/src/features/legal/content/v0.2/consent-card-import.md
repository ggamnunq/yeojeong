# 「여정」 카드 내역 조회 동의서

버전 0.1 · 시행일 2026-10-30

## [필수] 개인(신용)정보 수집·이용 동의 (카드 내역 조회)

김준용(이하 "운영자")은 「여정」의 카드 내역 불러오기 기능을 제공하기 위하여 「개인정보 보호법」 제15조와 「신용정보의 이용 및 보호에 관한 법률」 제15조에 따라 아래와 같이 개인(신용)정보를 수집·이용합니다.

카드 내역 불러오기는 **시범 운영 중인 기능**으로, 운영자가 이용 권한을 부여한 회원만 이용할 수 있습니다. 이 동의는 그 회원이 카드 내역 불러오기를 처음 이용할 때 받으며, 동의하지 않은 회원의 개인정보는 이 동의서에 따라 처리하지 않습니다.

**수집 출처**: 회원이 고른 카드사(회원이 입력한 로그인 정보로 조회)

| 수집·이용 목적 | 수집 항목 | 보유·이용 기간 |
|---|---|---|
| 카드사 로그인과 카드 승인내역 조회 | 카드사 이름, 카드사 로그인 아이디와 비밀번호(비밀번호는 회원의 브라우저에서 암호화하여 전달하며, 운영자는 원문을 볼 수 없습니다) | **저장하지 않습니다. 조회를 마치면 즉시 파기합니다** |
| 현대카드·하나카드의 카드 승인내역 조회(두 카드사가 로그인 외에 추가로 요구하는 정보) | 카드번호(전체), 카드 비밀번호(현대카드 4자리, 하나카드 앞 2자리). 카드 비밀번호는 회원의 브라우저에서 암호화하여 전달하므로 운영자는 원문을 볼 수 없습니다. 카드번호는 암호화된 연결(HTTPS)로 운영자의 서버를 거쳐 헥토데이터(CODEF)로 전달합니다 | **저장하지 않습니다. 조회를 마치면 즉시 파기합니다** |
| 카드사가 요구하는 추가 인증(현대카드·하나카드는 추가 인증 없음) | 문자 인증번호, 추가 인증 진행 정보(회원의 브라우저에 암호화하여 보관) | **저장하지 않습니다. 인증을 마치거나 160초(약 2분 40초)가 지나면 파기합니다** |
| 불러온 결제를 보여 주고 추가할 결제 고르기 | 회원이 정한 조회 기간(최대 92일, 오늘부터 1년 이내. 카드사에 따라 더 짧을 수 있음)의 카드 승인내역: 승인 일시, 가맹점명, 승인 금액과 통화, 원화 청구 금액, 해외 승인 여부, 승인·취소 구분 | **운영자의 서버에 저장하지 않습니다. 회원의 화면에 보여 주는 데에만 쓰고, 결제를 추가하거나 화면을 나가면 파기합니다** |
| 회원이 고른 결제의 지갑 기록, 같은 결제의 중복 추가 방지 | 회원이 고른 결제의 결제 일시(날짜·시각), 금액, 통화, 가맹점명, 카드사 원화 청구 금액(있는 경우), 중복 확인값(카드사·승인번호·승인 일시·승인 금액·통화를 운영자의 비밀키로 되살릴 수 없게 변환한 값. 승인번호 원문은 저장하지 않습니다) | **직접 입력한 결제와 같습니다. 여정에 연결된 결제는 여정 종료일부터 3년, 지갑에만 있는 결제는 회원이 삭제하거나 탈퇴할 때까지**(마지막 로그인일부터 3년 동안 이용하지 않으면 탈퇴로 보아 삭제) |
| 조회 이력 관리와 보안 | 회원, 조회 일시, 카드사 코드, 건수, 결과 코드(불러온 내역의 내용은 남기지 않음) | **1년** |
| 카드사 로그인 잠김 예방과 과도한 조회 제한 | 회원, 카드사 코드, 로그인 실패 횟수와 마지막 실패 시각, 조회 횟수 제한 기록 | **7일**(이후 파기) |

**조회의 위탁**
조회는 운영자가 위탁한 주식회사 헥토데이터(CODEF)가 회원을 대신하여 카드사에 로그인하는 방식으로 처리합니다. 운영자는 조회를 위한 헥토데이터의 연결 정보를 만들지 않으며, 예비 조회 방식에서 연결 정보를 만들면 **조회 직후 삭제합니다**(일시적 오류로 삭제가 늦어지면 회원을 알아볼 수 있는 정보 없이 연결 식별값만 암호화하여 보관하고, 삭제 외의 목적으로 쓰지 않으며, 삭제될 때까지 다시 시도합니다). 수탁자, 위탁 업무, 처리하는 정보는 「개인정보 처리위탁 고지」(https://jinyeojeong.com/privacy/processors)에서 확인할 수 있습니다.

**조회 방식**
- 회원이 불러오기를 할 때마다 한 번만 조회합니다. 자동으로 다시 조회하지 않으며, 다시 불러오려면 로그인 정보를 다시 입력하여야 합니다.
- **조회 전용**입니다. 운영자는 결제, 취소, 이체 등 어떠한 거래도 하지 않습니다.
- 회원 본인 명의 카드사 계정과 카드의 정보만 입력할 수 있습니다.
- 카드사 로그인 아이디와 카드번호는 암호화된 연결(HTTPS)로 운영자의 서버를 거쳐 헥토데이터(CODEF)로 전달되며, 운영자는 이를 저장하거나 서비스 로그에 남기지 않습니다. 비밀번호와 카드 비밀번호는 회원의 브라우저에서 암호화되므로 운영자는 원문을 볼 수 없습니다.
- 같은 카드사에 로그인이 연속하여 실패하거나 짧은 시간에 여러 번 조회하면, 카드사 계정 잠김을 막기 위하여 일정 시간 조회를 제한합니다.

**수집하지 않는 정보**
카드 유효기간과 CVC, 주민등록번호, 공동인증서, 카드 이용 한도·결제 예정 금액·포인트 등 승인내역 밖의 정보. 카드 끝 4자리와 카드 이름도 수집하지 않습니다(조회 결과에 들어 있더라도 저장하거나 화면에 보내지 않고 바로 버립니다).

**추가한 결제의 공개**
추가한 결제는 처음에 **회원 본인에게만** 보입니다. 결제 일시가 회원이 참여한 여정의 기간에 들면 그 여정에 미확정 결제로 연결되며, 회원이 "공동"으로 정한 결제만 같은 그룹 멤버에게 보입니다. 직접 입력한 결제와 같은 규칙을 따릅니다.

**동의를 거부할 권리와 거부 시 불이익**
귀하는 위 개인(신용)정보 수집·이용에 대한 동의를 거부할 권리가 있습니다. **동의를 거부하시면 카드 내역 불러오기를 이용할 수 없습니다. 이 경우에도 결제를 직접 입력하여 지갑과 여정 기능을 그대로 이용할 수 있으며, 나머지 서비스 이용에는 제한이 없습니다.**

**동의의 기억과 철회**
- 한 번 동의하면 다음에 카드 내역 불러오기를 이용할 때 다시 묻지 않습니다. 동의를 철회했거나 이 동의서가 바뀌어 다시 동의가 필요한 경우에는 다시 묻습니다.
- 마이페이지 > 동의 관리에서 언제든지 철회할 수 있습니다. 철회하면 다시 동의하기 전까지 카드 내역 불러오기를 이용할 수 없습니다.
- 이미 지갑에 추가한 결제는 회원이 직접 골라 추가한 기록이므로 철회한 뒤에도 그대로 남으며, 회원이 지갑에서 언제든지 삭제할 수 있습니다.

그 밖의 처리 내용은 「개인정보 처리방침」(https://jinyeojeong.com/privacy)에서 확인할 수 있습니다.
